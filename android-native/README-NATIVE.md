# Tege — нативный Android-клиент

Это отдельное приложение на Kotlin + Jetpack Compose в `android-native/`. Оно не использует WebView или Capacitor и не является веб-сайтом, упакованным в APK.

## Структура

- `app/src/main/java/org/tege/messenger/MainActivity.kt` — точка входа и навигация.
- `ui/screens/` — авторизация, список чатов, диалоги, профиль, каналы и настройки.
- `viewmodel/TegeViewModel.kt` — состояние приложения, аккаунты, локальная история и серверные события.
- `service/BackendClient.kt` — HTTP-авторизация и WebSocket-клиент.
- `model/Models.kt` — модели сообщений и экранов.

## Сборка APK

GitHub Actions workflow **Build Native Android APK (Kotlin + Compose)** собирает именно нативный проект:

1. Откройте [Actions](https://github.com/negr7082-arch/tege.new/actions).
2. Выберите **Build Native Android APK (Kotlin + Compose)** и откройте успешный запуск для нужного коммита.
3. Скачайте артефакт `Tege-Native-Debug-APK`; внутри находится `app-debug.apk`.

Workflow использует JDK 17, Android SDK 34 и Gradle 8.2.1. Wrapper Gradle пока не добавлен.

Локально при установленном JDK 17, Android SDK и Gradle 8.2.1:

```bash
cd android-native
gradle --no-daemon assembleDebug
```

Файл сборки: `app/build/outputs/apk/debug/app-debug.apk`.

## Что сейчас подключено

- Регистрация и вход по email/паролю через существующий API Tege.
- Сохранение серверного токена и повторное подключение WebSocket после обрыва.
- Получение реального каталога пользователей и статусов присутствия с сервера.
- Отправка и получение обычных личных текстовых сообщений, в том числе обработка очереди офлайн-доставки.
- Синхронизация редактирования и удаления собственных текстовых сообщений в личных диалогах.
- Локальное «Избранное», поиск по истории на устройстве, закрепление чатов, тема, обои и размер текста.
- Настройки показывают фактический статус подключения и дают переподключиться.

В списке диалогов нет заранее созданных фальшивых пользователей и демонстрационных переписок. Создание личного диалога использует зарегистрированного пользователя из серверного каталога.

## Ограничения — без скрытых обещаний

- Двухэтапный вход с облачным паролем пока не поддерживается в Android-клиенте.
- Голосовые/видеофайлы не загружаются на сервер; в серверных личных чатах запись голосовых сообщений отключена, чтобы не выдавать локальный файл за отправленный.
- Реакции, опросы и закрепления сообщений, созданные текущими локальными инструментами, пока не имеют серверного API; для реальных серверных диалогов такие локальные действия скрыты.
- Группы и каналы ещё не подключены к нативному клиенту как полноценный синхронизируемый обмен сообщениями.
- Push-уведомления Android, статусы доставки/прочтения и управление активными сессиями из приложения пока не реализованы.
- «Избранное», оформление и часть локальной истории сохраняются на этом устройстве. Очистка данных приложения удаляет эту локальную информацию.
- Нативный серверный обмен требует доступного HTTPS-сервера с API Tege. Для удалённых адресов клиент не разрешает обычный HTTP, чтобы не передавать пароль и токен открытым текстом; HTTP оставлен только для локальной разработки.

Сборка debug APK не заменяет проверку на реальном устройстве. Успешный результат указывается только после того, как завершится соответствующий запуск GitHub Actions.
